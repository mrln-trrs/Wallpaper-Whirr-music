# Política de seguridad

Este proyecto es un sitio estático sin servidor ni datos de usuarios: los archivos de audio que se añaden desde el equipo se reproducen solo en el navegador y no se envían a ningún sitio; la única información guardada (pista, posición, volumen y preferencias) queda en el `localStorage` del propio navegador.

Si encuentras un problema de seguridad, abre un issue en el repositorio con una descripción y los pasos para reproducirlo. Solo se mantiene la última versión publicada.
